# ELETRO-FAST-SITE - Especificações e Manutenção

## 1. Visão Geral do Projeto
O ELETRO-FAST-SITE é o site oficial (institucional/loja) de assistência e serviços elétricos em Curitiba. O desenvolvimento principal já está concluído. O foco atual do repositório é apenas manutenção, correções de bugs (bugfixes) e pequenos ajustes de conteúdo.

## 2. Stack Tecnológica e Padrões
* **Linguagens:** HTML5, CSS3, JavaScript puro (Vanilla).
* **Animações:** GSAP (ScrollTrigger) para interações e vídeos de fundo.
* **Cores Principais:** Azul Navy e Amarelo (ajuste com os códigos HEX exatos, se preferir).
